# EU-regulated CFD / FX / futures brokers drivable by API from Poland with a tiny account (Capital.com, cTrader, MT5, OANDA, Dukascopy, Saxo, IG, IBKR)

Research date: 2026-10-31. Confidence tags: [H] primary source read in full or clearly stated; [M] primary source via search summary, or single credible secondary; [L] affiliate/review site, forum anecdote, or undated. "Older than 12 months" means published before 2025-10-31 and is flagged "(OLD)". Everything not backed by a URL is listed under Inferences or Gaps.

RAM rule used throughout: no candidate below has a measured RSS for its Python client. Where a heavy runtime is required I give the only evidence found; otherwise "unmeasured".

## 1. Capital.com (CySEC) - REST / WebSocket API, demo, minimum deposit, order types, terms on automation

### Takeaway
Capital.com is the only candidate found that combines a free demo with API access, a documented REST + WebSocket API usable from a ~100 MB Python process, a 20 USD/EUR/GBP (100 PLN) minimum deposit and no deposit/withdrawal fees. Open items that decide go/no-go: the client agreement does not ban automation outright but bans "robots / high speed trading systems" that abuse the platform (vague), real shares for Polish clients are not confirmed, and share-CFD minimum size, spread and financing for Poland are unverified.

### Cited Findings
- Entity serving EU clients under the terms read: Capital Com SV Investments Ltd, Cyprus, HE 354252, CySEC licence 319/17, Limassol; governing law Cyprus. T&C version 19, February 2024 (OLD) — [Capital.com T&C v19](https://img.capital.com/docs/CCSV_terms_and_conditions_v19_feb_2024.pdf), clause 1.1 [H for that version]. Poland-focused reviews say Polish clients are served by this entity — [Invezz PL](https://invezz.com/pl/recenzje/capital-com/) [L]. Capital.com is not directly KNF-regulated (passported) — [comparebroker](https://comparebroker.io/brokers/is-capitalcom-legal-in-poland) [L].
- Newer reporting (2026-10-14/20) calls the entity taking over FxPro's Cyprus book "Capital Com Group Ltd, Capital.com's European entity"; CySEC approval of that deal is pending — [Cyprus Mail, 2026-10-20](https://cyprus-mail.com/2026/10/20/fxpro-agrees-to-transfer-cyprus-client-book-to-capital-com); [FX News Group](https://fxnewsgroup.com/forex-news/retail-forex/capital-com-acquires-fxpro-european-client-book/) [M]. The contracting entity for a new Polish client in late 2026 must therefore be confirmed in the current client agreement (newer than v19).
- Official API reference, base URLs: live `https://api-capital.backend-capital.com/`, demo `https://demo-api-capital.backend-capital.com/`; WebSocket `wss://api-streaming-capital.backend-capital.com/connect` — [Capital.com API docs](https://open-api.capital.com/) [H]. The docs' last changelog entry is 2023-11-28 (OLD; docs themselves undated).
- Auth/session: `GET /session/encryptionKey` (X-CAP-API-KEY header) then `POST /session` with identifier and password (optional encrypted password); response headers `CST` and `X-SECURITY-TOKEN` go on every later request; "Session is active for 10 minutes", both tokens valid 10 minutes after last use; keep alive with `GET /ping` (REST) or `ping` (WebSocket) — [API docs](https://open-api.capital.com/) [H]. An unofficial wrapper says the same — [python-capitalcom](https://github.com/tunga3109/python-capitalcom) [M].
- API key prerequisites: 2FA must be enabled before generating a key; key is shown once; the API password is separate from the platform password; keys are trading-capable and there are no read-only keys; the same key works on demo and live hosts; the only verification mentioned for key creation is e-mail — [Capital.com official MCP repo README](https://github.com/capital-com-sv/capital-mcp/blob/main/README.md) [M, README of an official-org repo, undated]. Nothing found says a live (KYC-approved) account is needed to generate a key for the demo host [gap, see below].
- Rate limits: general 10 requests/s per user; opening positions or creating orders 1 request per 0.1 s per user; `POST /session` 1 request/s per API key; demo `POST /positions` and `POST /workingorders` 1,000 requests/hour (set 2022-03-23); demo balance cannot exceed 100,000; `POST /accounts/topUp` (added 2023-11-28) tops up demo — [API docs](https://open-api.capital.com/) [H].
- WebSocket: max 40 instruments (epics) per subscription for market data and for OHLC; OHLC resolutions MINUTE to WEEK; session lasts 10 minutes (ping at least every 10 minutes); streaming stops if the account is switched via `PUT /session` — [API docs](https://open-api.capital.com/) [H].
- Order types over API: `POST /positions` (BUY/SELL, epic, size, optional `guaranteedStop`, `trailingStop`, `stopLevel`, `stopDistance`, `stopAmount`, `profitLevel`, `profitDistance`, `profitAmount`); `POST /workingorders` with type LIMIT or STOP, `level`, optional `goodTillDate` (UTC) and the same stop/profit parameters; trailing stop needs `stopDistance` and cannot combine with a guaranteed stop; guaranteed stop cannot be set in hedging mode; "Stop loss and take profit cannot be set on real stock trades" — [API docs](https://open-api.capital.com/) [H]. Consequence: a broker-side stop is attachable atomically to a CFD position, not (per docs) to a real-share trade.
- Activity history queries are limited to a 1-day range (2023-07-04) — [API docs changelog](https://open-api.capital.com/) [H] (relevant to reconciliation design).
- The official MCP server wrapper says "All orders placed through the Public API are executed as market orders" and the API "may be modified, rate-limited, suspended, or discontinued at any time without prior notice" — [capital-mcp README](https://github.com/capital-com-sv/capital-mcp/blob/main/README.md) [M]. The first sentence describes that wrapper's behaviour; it conflicts with the API reference listing LIMIT/STOP working orders, so treat it as a wrapper limitation.
- Minimum deposit (EU fee page): "20 USD/EUR/GBP or 100 PLN"; wire transfer minimum 50 EUR; no account opening/closing fee, no deposit fee, no withdrawal fee; minimum card withdrawal 20 (lower amounts only as full balance); currency conversion markup "0.4% of spot forex rate" applied to buys, sells and corporate actions when instrument currency differs from account currency (text is written for stocks/real instruments); regulatory fees passed through — [Capital.com EU fees page](https://capital.com/en-eu/ways-to-trade/fees-and-charges) [H, undated]. Conflicting third-party figures ($20 vs $250 bank transfer vs 10 EUR cards) exist — [Invezz PL](https://invezz.com/pl/recenzje/capital-com/) [L].
- Inactivity: account with no open or closed positions for 1 year is "Inactive"; a fee of 10 USD/GBP/EUR per month applies after 12 consecutive months of that status (clause 5.13); Capital.com may close inactive accounts and refund funds (8.19) — [T&C v19](https://img.capital.com/docs/CCSV_terms_and_conditions_v19_feb_2024.pdf) [H for that version, OLD].
- Guaranteed Stop Loss (GSL): exists in the T&C; fee is charged only when the GSL triggers, as an extra spread, formula `GSL Fee = GSL Premium × Position Open Price × Quantity`, shown on the deal ticket; not available in hedging mode or on MT4 (clause 5.15); French clients get a mandatory GSL (annex) — [T&C v19](https://img.capital.com/docs/CCSV_terms_and_conditions_v19_feb_2024.pdf) [H for that version, OLD]. Whether GSL is offered for a given share CFD to Polish clients is not stated. A BrokerChooser review (updated June 2026) claims no GSL on desktop — [BrokerChooser](https://brokerchooser.com/de/broker-reviews/capitalcom-review/capitalcom-scam) [L, contradicts the T&C and API docs].
- Terms on automation: clause 8.12 "Improper or Abusive Trading" lists "(b) use of an automated data entry system, mass data entry system, any electronic devices, robots, high speed trading system, or any kind of software or program, or automated software algorithms which might manipulate, alter, tamper with or otherwise abuse our Online Trading Platform"; and "(g) ... any device, software, program, algorithm or any trading strategy that aims to manipulate, alter, tamper with or take unfair advantage of our Services or Platform". Clause 13.1.1(h) has the client warrant not to use a "Device" aimed at unfair advantage from the way prices are constructed, "or use any kind of automated data entry system, robots, high speed trading system". The text also says "price misquotations are likely to occur from time to time" in streaming prices (8.12.1). Consequences listed include cancelling trades and terminating the agreement. Clause 8.25.3 mentions expert advisors/robo advisors "(where these are permitted)" for MT4 — [T&C v19](https://img.capital.com/docs/CCSV_terms_and_conditions_v19_feb_2024.pdf) [H for that version, OLD; read by extracting the PDF, two-column layout so quotes are reconstructed]. No clause found that bans API trading by retail clients; Capital.com publishes the API itself.
- Negative balance protection: clause 8.20 (T&C v19) [H, OLD]. Investor protection: CySEC Investor Compensation Fund up to EUR 20,000 plus a private insurance policy up to EUR 1 million for EU retail clients effective 1 June 2025 (Belgium reportedly excluded) — [Capital.com press release](https://capital.com/en-eu/press/capital-com-enhances-eu-client-protection); [Finance Magnates](https://www.financemagnates.com/forex/capitalcom-adds-1m-eu-client-fund-insurance-on-top-of-cysecs-20k-protection/amp) [M].
- Real shares: Capital.com announced on 2026-09-28 commission-free direct investing in stocks and ETFs "for eligible clients across nearly all of its EEA markets" (2,280+ instruments, US and European, execution-only); Poland is not named, the entity is not named, API support/fractional/minimums not mentioned — [Finance Magnates, 2026-09-28](https://www.financemagnates.com/forex/capitalcom-goes-beyond-cfds-launches-stocks-and-etfs-in-europe/) [M]; also [Cyprus Mail, 2026-09-28](https://cyprus-mail.com/2026/09/28/capital-com-expands-into-stocks-and-etfs-across-europe) (search-result summary only).
- Financing: overnight funding on non-leveraged (1:1) share and crypto CFDs set to 0% from 2024-07-08 (OLD); other leverage ratios and markets unaffected; the page does not say it covers EU retail — [Capital.com press release, 2024-07-08](https://capital.com/en-eu/press/capital-com-introduces-0-overnight-funding-to-support-investment-style-trading) [M]. An Australian fee page describes overnight funding as benchmark rate (e.g. SOFR for USD underlyings) plus/minus 0.01096% per day (4% p.a.) — [Capital.com AU fees](https://capital.com/en-au/ways-to-trade/fees-and-charges) [L-M, regional, from search summary]. Charge time conflicts between sources (21:00 vs 22:00 UTC) — [forexbrokers.com](https://www.forexbrokers.com/reviews/capital-com/fees); [Capital.com share page](https://capital.com/capita-share-price) [L].
- Capital.com also offers MT4/MT5 and TradingView, per its navigation menu — [capital.com](https://capital.com/api-general-information) [L, navigation only].
- RAM: Python REST (e.g. `httpx`/`aiohttp`) + one WebSocket; no runtime other than Python. Footprint unmeasured by any source found.

### Inferences
- Because the session dies after 10 minutes of inactivity and re-login is a plain call with API key + identifier + password (no interactive step documented after the one-time 2FA at key creation), an unattended 24/7 asyncio process is feasible: ping every <10 min, re-login on 401, serialise `POST /session` (1/s). [M]
- Atomic stop on position creation (`stopLevel`/`stopDistance`) fits the ORB design's "broker-side stop"; for real-share trades the documented ban on SL/TP means the stop would have to be a separate working order or engine-held, which breaks the broker-side-stop requirement. Use share CFDs, not real shares, for the stop-protected phase. [M]
- Clause 8.12/13.1.1 is written against abuse (latency arbitrage, price manipulation), not against rule-based retail automation, and the vendor ships and documents the API; the residual risk is a vague "high speed trading system" wording applied discretionally. An ORB strategy with a few trades a day is far from that pattern, but written confirmation from support is cheap and should be obtained before live money. [M]
- The demo order cap (1,000/hour) is not binding for an intraday strategy but must be respected in paper tests with many symbols.
- 40 epics per subscription is enough for a small watchlist; larger universes need several subscriptions (unverified whether more than one is allowed).

### Gaps
- Whether an API key can be generated for the demo host with only an e-mail-verified demo account (no KYC): not stated in any official page read.
- Actual minimum deal size, spread, leverage and overnight rate for a single US-share CFD for a Polish retail client: Capital.com's CFD fee page and instrument pages were not reachable (404/403). Use the API (`/markets/{epic}` returns dealing rules and bid/offer) on demo to measure.
- Whether the Polish Capital.com client is contracted with Capital Com SV Investments Ltd or a newer entity, and whether real shares/ETFs (launched 2026-09-28) are open to Poland and via API.
- Whether 8.12/13.1.1 has been rewritten after Feb 2024 (the PDF read is v19).
- Capital.com status/outage history and requote/rejection behaviour: not found.
- Capital.com's own statement on bots on live accounts: not found (only the T&C clauses above).

## 2. cTrader Open API route (Pepperstone EU, IC Markets EU, Skilling, FxPro and others serving Poland)

### Takeaway
cTrader Open API is the best-engineered protocol among the candidates (protobuf or JSON over TCP/WebSocket, explicit reconcile message, 50 requests/s, `clientOrderId`, refresh tokens that never expire) and needs no terminal, so RAM is not an issue. The obstacles are administrative: Spotware must approve the API application, the broker can disable Open API per account or per application, and no EU broker's own documentation confirms Open API for Polish retail clients. FxPro's EU book is moving to Capital.com, so it is not a candidate.

### Cited Findings
- Protocol: messages are JSON or Google Protobuf; non-historical requests max 50/s per connection, historical max 5/s per connection; API is available to anyone registered with a cTrader-affiliated broker; official SDKs for C# and Python; "all possible types of trading operations permitted in official cTrader applications" — [cTrader Open API docs](https://help.ctrader.com/open-api/) [H].
- Endpoints: live `live.ctraderapi.com`, demo `demo.ctraderapi.com`; protobuf on port 5035 only, JSON on port 5036 only; both ports support TCP and WebSocket; live and demo are fully separate (two connections needed) — [Proxies and endpoints](https://help.ctrader.com/open-api/proxies-endpoints/) [H].
- Auth: OAuth 2.0; the user logs in in a browser once, redirects with a one-minute authorisation code; access token lifetime 2,628,000 s (about 30 days); refresh token has no expiry; refresh (HTTP `grant_type=refresh_token` or `ProtoOARefreshTokenReq`) returns new access and refresh tokens and "the old values are invalidated"; app auth `ProtoOAApplicationAuthReq`, then `ProtoOAGetAccountListByAccessTokenReq`, then `ProtoOAAccountAuthReq` per account; accounts created later are not authorised automatically — [Account authentication](https://help.ctrader.com/open-api/account-authentication/) [H].
- App registration: register at the Open API portal; "After receiving approval from Spotware, you should proceed with coding"; Spotware "carefully evaluates new Open API services"; a redirect URI is mandatory; review time and personal-use rules not stated — [Creating a new app](https://help.ctrader.com/open-api/creating-new-app/) [H].
- Broker gate: a cTrader forum moderator: the API is enabled by default for all cTrader brokers, but a broker can block specific API applications; reports of `TRADING_DISABLED` on demo, orders working on demo but not live until the broker enabled Open API on the live account; one broker's support (named Pepperstone in the post) did not know the difference between FIX API and Open API and said "email us and ask to activate API access"; forum posts 2019-2024 (OLD) — [forum 42755](https://community.ctrader.com/forum/connect-api-support/42755); [forum 39408](https://communityuat.ctrader.com/forum/connect-api-support/39408); [forum 13973](https://community.ctrader.com/forum/connect-api-support/13973/) [M].
- Order model: `ProtoOANewOrderReq` supports orderType MARKET, LIMIT, STOP, MARKET_RANGE, STOP_LIMIT; timeInForce GTD/GTC/IOC/FOK/MARKET_ON_OPEN; absolute `stopLoss`/`takeProfit` (not supported for MARKET orders), `relativeStopLoss`/`relativeTakeProfit` (1/100000 price unit), `trailingStopLoss` flag, `guaranteedStopLoss` flag only for Limited Risk accounts, `slippageInPoints` for MARKET_RANGE and STOP_LIMIT, `clientOrderId` max 50 chars; volume in 0.01 of a unit; `ProtoOAExecutionEvent` carries `isServerEvent` (e.g. stop-out); `ProtoOAReconcileReq/Res` returns open positions and pending orders — [Messages](https://help.ctrader.com/open-api/messages/) [H].
- Python SDK: Spotware's `OpenApiPy` (`ctrader-open-api` 0.9.2, MIT) uses Twisted + protobuf and Twisted deferreds, wheel about 24 kB — [GitHub](https://github.com/spotware/OpenApiPy); [PyPI](https://pypi.org/project/ctrader-open-api) [H/M]. Third-party asyncio client `ctrader-api-client` 0.4.2 (Python 3.12+, raw TCP port 5035 with SSL, "early development, API may change") — [PyPI](https://pypi.org/project/ctrader-api-client/0.4.2/) [M]. Both: RAM unmeasured. JSON on port 5036 means an asyncio + `websockets` client is possible without any SDK [inference].
- Pepperstone EU Limited: Cyprus company HE 398429, CySEC licence 388/20; official FAQ "Pepperstone doesn't set a minimum deposit" — [Pepperstone support](https://pepperstone.com/en-eu/support/whats-the-minimum-deposit-for-a-live-account) [H]; [Pepperstone EU share CFDs](https://pepperstone.com/en-eu/trading/instruments/share-cfds) (© 2025, entity data) [M-H]. Pepperstone's EU "API trading" production page lists cTrader Automate and algorithmic trading but says nothing about Open API or eligibility — [Pepperstone EU](https://pepperstone.com/en-eu/platforms/integrations/api-trading) [H]. A staging-domain copy of that page was reported to say FIX demo access needs at least EUR 160m monthly volume — [staging copy](https://next.stg.pretrade.pepperstone.com/en-eu/platforms/integrations/api-trading) [L: staging site, search summary only, not seen on the production page].
- Pepperstone EU share CFD commission: US shares and ETFs 0.02 USD per share per side (minimum 0.02 USD); Germany, France, Spain etc. 0.10% per side (minimum 0.01 EUR); "leverage up to 1:20" stated on the page (conflicts with the ESMA 5:1 single-share cap for retail given in the brief; the page may describe another client category); MT5 named for share CFDs, cTrader and TradingView in the commission table — [Pepperstone EU share CFDs](https://pepperstone.com/en-eu/trading/instruments/share-cfds) [M].
- IC Markets (EU) Ltd: CySEC 362/18; minimum deposit reported as 200 (USD or EUR, sources differ); cTrader Raw Spread account listed for EU; ICF cover EUR 20,000 — [TradingFinder](https://tradingfinder.com/brokers/icmarkets-eu); [InvestingLive](https://investinglive.com/brokers/ic-markets) [L]. No IC Markets statement on Open API found.
- Skilling (CySEC): EU standard minimum deposit reported as 100 EUR/GBP/USD; cTrader offered; no source confirms Open API — [Daytrading.com](https://www.daytrading.com/skilling) [L].
- FxPro: Capital.com agreed (announced 2026-10-14) to take over the client book of FxPro's Cyprus entity, subject to CySEC approval and per-client eligibility; FxPro keeps its UK licence — [Cyprus Mail, 2026-10-20](https://cyprus-mail.com/2026/10/20/fxpro-agrees-to-transfer-cyprus-client-book-to-capital-com) [M]; [FX News Group](https://fxnewsgroup.com/forex-news/retail-forex/capital-com-acquires-fxpro-european-client-book/) [M].
- The Polish brokerchooser "best cTrader brokers in Poland" page could not be read (HTTP 403), so no independent list of cTrader brokers actually serving Poland was obtained.

### Inferences
- The engine design maps almost 1:1 onto cTrader: `clientOrderId` for idempotent intent, `ProtoOAReconcileReq` for startup/reconnect reconciliation, `ProtoOAExecutionEvent` stream as the event source, `isServerEvent` for stop-outs, relative SL/TP or `AmendPositionSLTPReq` after the fill (absolute SL is rejected on MARKET orders, so entry-then-amend or relative SL is required). [M]
- Unattended operation: initial browser OAuth by a human once; after that refresh before the ~30-day expiry and persist the new pair atomically (old pair is invalidated, so a crash between refresh response and write would lock the app out until a new OAuth round). [M]
- The real gate is two human approvals (Spotware app review, broker enabling Open API) with unknown turnaround; forum evidence suggests broker support is inconsistent. This must be tested with a free demo before any deposit. [M]
- Pepperstone's per-share commission (0.02 USD) is cheap for expensive stocks and 0.1% per side for 20 USD stocks; see section 5. [M]
- RAM: protobuf/JSON over one TCP connection is lightweight; Twisted adds a reactor but no known heavy dependency. Expected well under 100 MB, but unmeasured. [L]

### Gaps
- Whether Pepperstone EU, IC Markets EU or Skilling actually grant Open API to a Polish retail client on a live account, and on what conditions (volume thresholds, per-account switch): no official statement found.
- Spotware review turnaround and whether a private, single-user app is accepted.
- Minimum volume/step for FX and share CFDs on each broker's cTrader symbols (decides whether 20 USD can trade at all).
- Reliability of Open API in 2026 (outages, token issues): no 2026 reports found; the forum evidence is 2019-2024.
- Heartbeat interval and connection timeout details ("Establish a connection" tutorial URL returned 404); the endpoints page does not cover them.
- Skilling's and IC Markets' Poland availability and Polish-language terms.

## 3. MetaTrader 5 brokers (Admirals, XM, Exness EU, FP Markets, Tickmill) and driving MT5 without a Windows terminal

### Takeaway
MT5 is not a practical route on this VPS: the only Linux options are Wine (a ~500-600 MB container by the one measurement found, i.e. most of the 700 MB free) or a paid third-party cloud (MetaApi) that holds the broker password. Treat MT5 as a fallback only when a broker offers nothing else.

### Cited Findings
- `mt5linux` (MIT, v1.1.1 released 2026-08-04) runs MetaTrader 5 on Linux with Wine + RPyC + a standalone `mt5server.exe`; modes: library-managed Docker, manual Docker (port 18812) or standalone Wine; releases not published via Trusted Publishing (no provenance) — [PyPI mt5linux](https://pypi.org/project/mt5linux/) [H].
- RAM evidence: the Docker image `hudsonventura/mt5` (Ubuntu 24.04, Openbox, TigerVNC, noVNC, Wine, MT5 and a watchdog that exits if MT5 crashes) "typically consumes around 500MB of RAM (depending of broker)"; compose comment says about 600 MB and suggests a 1024m limit; image updated "8 months ago"/"about 1 year ago"; the page does not mention Python access; MT5 is downloaded at first run; broker servers may need manual search over VNC — [Docker Hub](https://hub.docker.com/r/hudsonventura/mt5) [M-H]. No measurement of `terminal64.exe` alone, of a headless Xvfb setup, or of RPyC overhead was found.
- MetaApi cloud: "Supports any MetaTrader broker. Same stable API for both MT4 and MT5"; Python SDK wraps REST and WebSocket (needs Python 3.8+); API token auth; "MetaApi is a paid service, however we may offer a free tier access in some cases" — [metaapi.cloud](https://metaapi.cloud/); [metaapi-python-sdk](https://github.com/metaapi/metaapi-python-sdk) [H]. Pricing seen on the homepage via search summary: API access to one MetaTrader account free; Regular plan USD 30/month; Extended USD 100/month (ex VAT); the pricing widget showed an error so live prices may differ — [metaapi.cloud](https://metaapi.cloud/) [L-M]. Per-account hourly billing applies to the separate risk-management add-on.
- XM (EU entity CySEC): reviews say a micro account opens with USD 5 and EAs are allowed on MT5 — [Daytrading.com XM (PL)](https://www.daytrading.com/xm?geo=PL) [L, affiliate]. No XM primary document read.
- Admirals: Admirals Europe Ltd (CySEC) stopped onboarding EU clients in a week-in-review dated April 2024 (OLD), reasons given as a EUR 10m 2023 loss; later reporting says the 2024 EU onboarding pause hit activity and the UK entity migrated EU-resident clients out — [FX News Group (OLD)](https://fxnewsgroup.com/forex-news/retail-forex/fx-week-in-review-capital-com-strategy-shift-admirals-onboarding-halt-wahed-ceo/); [Finance Magnates](https://www.financemagnates.com/forex/brokers/admirals-uk-migrated-eu-resident-clients-out-2024-trading-volume-took-a-hit/) [M]. Current (2026) status for Polish clients not found.
- Capital.com's T&C describe MT4 as a third-party platform provided "as is", and EAs/copy-traders/robo-advisors "where these are permitted" — [T&C v19](https://img.capital.com/docs/CCSV_terms_and_conditions_v19_feb_2024.pdf) [H, OLD].
- Official `MetaTrader5` Python package is Windows-only (given in the brief; consistent with `mt5linux` needing Wine) — [PyPI mt5linux](https://pypi.org/project/mt5linux/).

### Inferences
- Self-hosted Wine MT5: 500-600 MB plus Python plus the other containers exceeds the ~700 MB free RAM with swap already at 1.1/2 GB; swapping a terminal that holds an open trade is a reliability risk. Reject on this VPS (could run on a separate 1-2 GB VPS if one is ever acceptable). [M]
- MetaApi removes the RAM problem but adds a monthly cost beyond the free single account, a US/EU third-party SaaS dependency, and requires giving it the MT5 account credentials (a trading password) - a security concern for an unattended bot; reliability/outage history was not researched. [M]
- Order/stop semantics and demo realism would be the broker's MT5 server, so MT5 gives no advantage in order model over cTrader or Capital.com except in the number of brokers.

### Gaps
- Current MetaApi price list and SLA; any independent reliability report.
- Measured RSS for headless Wine+MT5 without VNC/noVNC.
- Exness EU, FP Markets EU, Tickmill EU: availability to Polish retail, EA policy and minimum deposit were not checked with primary sources (time-boxed).
- Admirals/XM 2026 status and terms.

## 4. OANDA, Dukascopy Europe, Saxo, IG, Interactive Brokers (CFDs / futures), FXCM and other EU venues

### Takeaway
None of these is better than Capital.com or cTrader for a 20 USD account: OANDA's v20 API excludes the Polish OANDA TMS entity; Dukascopy needs Java and 100,000 USD for FIX; IBKR needs a Java gateway; Saxo's unattended flow depends on refresh-token chaining and its minimums are high; IG's API is real and works with Lightstreamer quirks but eligibility for Polish clients of IG Europe GmbH is unconfirmed.

### Cited Findings
- OANDA: v20 docs state "To use this API you must have a v20 trading account, which is available to all divisions except OANDA Global Markets and OANDA TMS BROKERS S.A." — [OANDA developer intro](https://developer.oanda.com/rest-live-v20/introduction/) [H on text, page undated, site copyright 2019: OLD]. OANDA moved its EU operations from Malta to Warsaw under KNF in 2023 (OANDA TMS) — [Finance Magnates](https://www.financemagnates.com/forex/oanda-to-exit-malta-in-march-to-run-european-business-from-poland/); [OANDA press release](https://www.oanda.com/group/press-release/new-operations-in-the-eu/) [M, OLD]. OANDA Europe Limited (FCA, UK) is listed on the developer site but is not an EU entity — [developer.oanda.com](https://developer.oanda.com/) [M]. No 2026 source confirming v20 for EU retail was found.

## 5. Costs, what 20 USD and 1,000 USD can actually trade, and where CFDs change the research conclusions

### Takeaway
At 20 USD the ESMA 5:1 cap gives about 100 USD notional on single-share CFDs (30:1 on major FX about 600 USD), so tradable size is limited by each broker's minimum volume, which is unverified. Per-share commission brokers (Pepperstone) cost about 0.2% per round trip on 20 USD stocks; spread-only brokers (Capital.com) cost about one spread. CFDs add financing, gap risk on stops, spread widening at the open and no share ownership, which change the strategy conclusions.

### Cited Findings
- ESMA retail limits (as given in the brief): 30:1 major FX, 20:1 non-major FX / gold / major indices, 10:1 commodities and other, 5:1 single shares, 2:1 crypto, 50% close-out, negative balance protection.
- Pepperstone EU: US share CFD commission 0.02 USD per share per side, minimum 0.02 USD; EU shares 0.10% per side — [Pepperstone EU](https://pepperstone.com/en-eu/trading/instruments/share-cfds) [M].
- Capital.com: no commission line found for share CFDs (CFD fee page unreachable); FX conversion markup 0.4% of spot on instruments in a different currency from the account; no deposit/withdrawal fee; inactivity 10 per month after 12 months; financing 0% only for 1:1 share CFDs (2024-07-08, OLD) — see section 1 sources.
- Capital.com GSL: extra spread charged only when triggered — [T&C v19](https://img.capital.com/docs/CCSV_terms_and_conditions_v19_feb_2024.pdf) [H, OLD].
- Capital.com financing formula (regional page): benchmark ± 4% p.a. (0.01096%/day) — [Capital.com AU](https://capital.com/en-au/ways-to-trade/fees-and-charges) [L-M].

### Inferences
Worked arithmetic (inputs marked A are my assumptions, not sourced; replace with measured demo data):

1. Margin capacity at ESMA limits (verified leverage, arithmetic only): 20 USD account, 5:1 shares -> max notional about 100 USD (before any safety buffer and the 50% close-out); 1,000 USD -> 5,000 USD. 30:1 major FX: 20 USD -> about 600 USD; 1,000 USD -> about 30,000 USD. If the broker's minimum FX volume is 1,000 units of EUR (about 1,100 USD at an illustrative 1.10 USD/EUR, A), the 20 USD account cannot open it at 30:1 (needs about 37 USD margin); it needs a step of 1-500 units. Same logic for index CFDs: minimum contract value must be below 20 × 20 = 400 USD notional.
2. Pepperstone EU US share CFD round trip commission (verified rate; assumes fractional/small volumes are allowed, A): stock price 200 USD, notional 20 USD = 0.1 share: raw 0.002 USD per side, minimum 0.02 -> 0.04 USD round trip = 0.20% of notional. Notional 1,000 USD = 5 shares: 0.10 per side -> 0.20 round trip = 0.02%. Stock price 20 USD: notional 20 USD (1 share) -> 0.04 round trip = 0.20%; notional 1,000 USD (50 shares) -> 2.00 round trip = 0.20%. If the minimum is 1 whole share, a 20 USD account at 5:1 can only trade stocks priced below about 100 USD.
3. Spread (A: 0.05% of price paid once per round trip, as in the earlier report's assumption): 20 USD notional -> 0.01 USD; 1,000 USD -> 0.50 USD. At A = 0.10% -> 0.02 and 1.00 USD. Capital.com share-CFD costs are spread-only if no commission applies [unverified], so the round trip is about 0.05-0.10% plus any financing; Pepperstone adds the commission above to its (usually tighter) spread.
4. FX conversion: if the account currency differs from the instrument currency and the 0.4% markup applies to CFD P&L (unverified; the fee text is written for stocks), a round trip of two conversions is 0.8% -> 0.16 USD on 20 USD, 8.00 USD on 1,000 USD. Keep the account in the instrument currency (USD) to avoid it.
5. Overnight financing (illustrative A: benchmark 4% + 4% = 8% p.a.): 0.0219% per night -> 0.022 USD on 100 USD notional, 1.10 USD per night on 5,000 USD; weekend charged three times at most brokers (A). An ORB engine that is flat by the close pays none; but a stop that fails to close or an engine outage with an open position pays it.
6. GSL: premium multiplies open price by quantity, charged only on trigger; on a tiny account the fee is cents but the guaranteed stop may be unavailable for share CFDs (unverified).
7. Inactivity (Capital.com): 10 per month after 12 months of no positions would erase a 20 USD account in two months; the engine must trade or the account be closed. [H on the clause, OLD document]

Where CFDs change the research conclusions (from the earlier US-stock report to a CFD route):
- No share ownership: no dividends; long positions get a dividend adjustment and short positions pay one (clause on corporate events, T&C v19); no shareholder rights; the broker is counterparty (market-maker model), so quotes, fills and stop-outs are the broker's, not the exchange's. The backtest data (IEX/SIP) is not the CFD quote stream; the engine should record the broker's own bid/ask stream and test the strategy on that.
- Leverage replaces the cash-only constraint of Alpaca: 5:1 on shares allows larger notional but magnifies a 20 USD loss; negative balance protection caps loss at the deposit.
- Shorting is available (no borrow search), which helps ORB breakdown trades; no PDT rule.
- Costs: spread plus commission vs the commission-free-but-fee-rounded Alpaca model; overnight financing on leveraged positions; FX conversion 0.4% where applicable; inactivity fee; GSL premium. Expect the opening-range window (US cash open 15:30 Warsaw time) to have the widest CFD spreads of the day [inference; no CFD-specific source found] - the stop-distance and entry-slippage model must be fitted to measured broker quotes at the open, not to a flat spread.
- Hours: Pepperstone advertises US share CFDs "24/5"; CFD prices outside the cash session may be broker-derived rather than exchange prices - exclude pre-market CFD quotes from signals unless validated [A, source: Pepperstone nav text only].
- Stop semantics: CFD stops are broker-server stops that fill at the next available broker price; gap risk remains without GSL; stop-fill quality, last look and requotes are not documented by any source read.
- Evidence gates: demo fills on CFD brokers are usually not exchange-grade (see section 6), so the paper-first gate proves plumbing, not edge; a tiny live phase is the first real cost evidence.

### Gaps
- Real spreads, minimum sizes, and financing rates for a US share CFD at Capital.com, Pepperstone, IC Markets for Polish retail: not found in primary sources (fee/instrument pages inaccessible); measure on demo.
- Polish tax treatment of CFD gains (PIT-38 category, PLN conversion) was not researched here.
- Whether any broker rounds or applies minimum fees per order that dominate at 20 USD.
